# Portal Web CEPDECO

El **Portal Web CEPDECO** es una plataforma de gestión académica desarrollada como un Producto Mínimo Viable (MVP) para la Corporación Educativa para el Desarrollo de Colombia (CEPDECO). El proyecto se realiza en el marco de la asignatura **Taller de Proyectos Interdisciplinarios 3 (TPI3)** de la **Universidad Nacional de Colombia (Sede de La Paz)**.

## 📌 Alcance del Proyecto (MVP)
* **Módulo de Usuarios:** Autenticación y control de acceso basado en roles (Administrador, Docente, Estudiante).
* **Módulo Académico:** Registro e ingreso de calificaciones por parte de los docentes y consulta de boletines por parte de los estudiantes.
* **Módulo de Certificación:** Generación y descarga automática de certificados académicos en formato PDF con un código QR dinámico para validación pública.
* **Módulo de Pagos (Simulación):** Integración con entorno Sandbox para la simulación completa del proceso de pago de trámites vía PSE y actualización de estado a "Paz y Salvo".
